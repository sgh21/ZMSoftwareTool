# 最终软件包验收

Windows 与麒麟应分别在未安装项目开发环境的目标系统执行。开发主机删减 PATH、容器启动及源码 pytest 均不能代替干净目标系统验收。

记录软件包文件名、大小、构建版本，操作系统完整版本、CPU 架构、屏幕缩放及验收日期；报告附真实截图和日志。人工样例仅验证软件，不能当成设备测量或模型效果证明。

## Windows 11 x86_64

1. 在干净 Windows 11 x86_64 虚拟机/新机器，以普通用户完整解压 Windows版.zip；软件目录移到带中文和空格的路径，例如 `C:\验收 软件\SoftwareTools`。不要装 Python、Conda、CUDA或开发工具；只按运行说明补明确列出的系统前置条件。
2. 将测试数据.zip 单独解压到软件目录之外。用 PowerShell 设置 `$env:ZMSOFTWARE_DATA_DIR="$env:TEMP\ZM_验收数据"`，切换到另一可写目录，再用完整路径启动 `SoftwareTools.exe`。验收后保留这份隔离目录作为证据，禁止指向生产数据。
3. 按下列公共清单操作。关闭后重新启动，确认机器人基准/历史、主轴模型/历史及窝深设置仍可加载。窝深导入记录当前仅在会话中保留，重启空数据属已知限制。
4. 检查程序资源、中文文字、图标、背景、三个页签和窗口缩放；启动和操作过程中无缺 DLL、Python、Qt 插件或资源路径错误。

需要复现自动检查时，在单独的验证机器安装 Python 和 `verification-requirements-windows.txt`，运行：

```powershell
python -m pip install -r verification-requirements-windows.txt
python verify_windows.py --exe "C:\验收 软件\SoftwareTools\SoftwareTools.exe" --test-data "C:\验收\测试数据.zip" --output "C:\验收\本轮报告"
```

脚本使用外部 Windows UIAutomation 与 Win32 控件操作真实 EXE，保存 JSON、截图和隔离业务存储。运行时请保持已登录、桌面解锁，勿同时运行其他 GUI 测试或操作鼠标键盘。输出目录必须是本轮新目录。该机器安装了验证依赖，应单独记录其环境；另做不装 Python 的纯人工检查。脚本不包含进软件本体。

## 麒麟 V10 桌面版 x86_64（海光 3550）

1. 记录 `cat /etc/os-release`、`uname -m`、`ldd --version`、`lscpu` 及桌面会话类型；必须为 x86_64。具体 SP/内核/glibc 版本以现场结果为准，不能只写“V10”视为已验证。
2. 在干净目标系统的普通账户中完整解压麒麟发布包，确认执行权限；将软件移动至带中文和空格的目录。不要安装项目 Python 或 Conda。按运行说明安装已列明的系统图形库前置条件。
3. 从其他目录执行：`ZMSOFTWARE_DATA_DIR="$HOME/ZM_验收数据" "/完整路径/SoftwareTools/SoftwareTools"`，将终端标准输出和错误保存为 `launch.log`。
4. 依次完成以下公共清单，截图；关闭重启验证持久化。将缺失共享库、Qt xcb/Wayland 插件、中文字体及权限问题原样记录；修复后重新检查最终打包产物。
5. 若只有构建容器或 CI，则只能记录“Linux 构建/容器启动通过”；麒麟实机、海光处理器以及干净桌面主要功能必须保留“未执行”。

## 公共功能清单

| 操作 | 通过条件 |
| --- | --- |
| 首次进入三个页面 | 均显示“评估精度”；无数据时禁用并给出悬浮操作提示；窝深导入按钮可用 |
| 机器人 JSON | 加载 `01_机器人/parameters.json`，导入 baseline JSON→建立基准→导入 current JSON→评估；当前重复定位精度 X/空间约 0.3266 mm；退化约 0.1633 mm；绝对退化约 0.6000 mm |
| 机器人导出 | 展开明细→导出结果到软件目录外；JSON 可读取，含 B002 批次、groups；UI 与导出匹配 |
| 机器人图像 | 另导入 images/B001/record.json 建立图片基准，再导入 B002/record.json 并评估；6 PNG 实际检测成功，观测图像可查看；不能混用 JSON 与图片基准 |
| 主轴导入分析 | 日常导入两个 simulated ZIP，HDF5/遥测/温度/曲线可读；ACC1 RMS 分别约 0.03606 与 0.14160 mm/s，频谱主峰 120 Hz；无模型时网络评分为空 |
| 主轴训练与推理 | 批量导入 小型建模.zip，仅为验收将这5次模拟采集判正常；训练网络设1轮；模型保存成功、历史重算完成，重新评估有网络结果；这不证明模型有效性 |
| 窝深 CSV/XLSX | 使用逐孔理论值，报警范围 [-0.1,0.1]；分别导入 normal/out_of_limit 的 CSV 和 XLSX，覆盖导入不报错；有效孔均5、均值1.500，方差分别0.000200和0.020000 |
| 缺测与边界 | out_of_limit 有2孔超限，1.4/1.6 mm 边界不超限，末行缺测不补零；孔位明细可查看 |
| 数据保存 | 参数、基准、主轴结果/模型、窝深设置写入指定隔离用户目录；软件安装目录不应出现业务数据 |
| 关闭与重启 | 正常关闭无残留软件进程，重启能读到应持久化的数据；无资源或依赖错误 |

逐项填“通过/失败/未执行”，附原因。只有真正执行了对应最终软件包才可写“通过”；同一文件修复重打包后，应重跑受影响的产物验收。
