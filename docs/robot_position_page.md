# 机器人定位精度监控页

机器人定位模块已接入本地参数、观测导入、基准管理、核心评估与历史。操作和输入格式见 [使用说明](robot_position_monitoring.md)。在线相机和控制器接口仍未接入，机器人运动由原设备软件负责。

## 监控依据

1. 采用已标定的相机到被评估末端（TCP）的手眼变换，不要求完整机器人运动学模型。手眼参数与初始测量基准分别管理，保留参数版本。
2. 机器人投入使用前，按固定程序、固定位姿拍摄靶标，保存初始观测基准。
3. 后续每次评估重复相同程序、位姿和靶标，通过视觉观测误差反映末端定位误差。机器人运动由原设备控制软件执行。
4. “机器人定位精度”标题右侧放置指标下拉菜单，独立于区域 1，标题与选择框垂直居中对齐。选项列表从框下方展开，不随当前选中项上下移动。菜单仅保留绝对定位精度退化、重复定位精度退化、当前重复定位精度，默认第三项，控制整个结果区。四列固定为基座 X、Y、Z 和空间指标，单位 mm；各项数学含义见使用说明。
5. 加工点位预测区域沿用当前所选指标，模型尚未接入，数值留空。加工点位与拍照观测点分别管理，预测值不能说成实测值。

视觉相对计算约定见本工程 [坐标换算与旧协议定义](robot_position_monitoring.md#坐标换算与旧协议定义)：相机与末端刚性连接，靶标相对基座固定，视觉输入包含完整旋转和平移，即使页面只展示位置指标也不能忽略视觉旋转。

用 `H` 表示相机到末端的手眼变换，`V_0`、`V_i` 表示基准、当前的靶标到相机变换。相对末端变换为 `ΔT_E = H V_0 V_i⁻¹ H⁻¹`，其平移 `p_ΔE` 在初始末端坐标系中表达。只有相对视觉数据时，基座 XYZ 还需每个测点的初始末端朝向 `R_E0`，按 `Δp_B = R_E0 p_ΔE` 转换；该朝向关联到基准数据，界面不增加坐标系选项。若已配置固定靶标基座外参 `A=B_T_M`，则可由 `X=A V⁻¹ H⁻¹` 直接恢复末端基座位姿。不能把缺少转换依据的末端系分量直接标成基座分量。

单次测量的距离 `||Δp_B|| = ||p_ΔE||` 代表相对基准的位置偏移，不直接等同于当前绝对定位误差，也不等同于前后误差模长之差。新多方向评估按专利 V6 先计算每点到位质心：菜单“绝对定位精度退化”显示质心漂移的各轴绝对分量与空间模；后两项显示质心 RMS 的变化和当前值，分母为方向数 D。各点等权汇总。菜单名称保留，提示、明细按结果自身的定义说明；旧多方向历史明确标注其 mean+3std / 3σ 与绝对误差模长差，旧同方向 RP 保持不变。完整定义和仿真理论值见 [使用说明](robot_position_monitoring.md)。加工点预测方法仍待确认。

## 固定区域编号

编号沿用用户 2026-09-24 标注截图，后续说“区域 N”按下表理解。编号仅用于沟通、文档和代码定位，界面不显示数字标号或编号说明。

常用窗口采用左侧结果、右侧设置，宽度约 65:35。字体、图标、间距与控件随窗口统一缩放；右栏设计最小宽度 332，同样参与缩放。页面可用宽度小于 1000 时改为结果在上、设置在下，避免裁掉设置栏，通过纵向滚动访问。采集、导入、清空日志、评估四个按钮在设置栏日志下方同排。

| 编号 | 内容 | 操作与职责 |
| --- | --- | --- |
| 1 | 评价更新时间、基准建立时间；X、Y、Z、空间指标四列 | 始终显示最新已评估观测相对所选基准的结果。各卡片按显示汇总值和该轴当前阈值独立标红；局部超限保留在报警详情，不使汇总未超限的卡片变红。时间按本地 `yyyy-MM-dd HH:mm:ss` 显示，缺失为“—” |
| 2 | 所选指标的历史趋势 | 标题固定为“定位精度趋势”，纵轴 mm。曲线统一相对当前基准计算，当前基准为第 0 天；“显示基准前历史”默认不勾选并保存选择，勾选后早期观测显示为负天数，不删除记录。真实观测按与基准的时间差绘制，保留真实间隔；优先采集时间，缺失时采用导入时间，旧记录可回退评估时间。仿真使用观测与基准已保存的 `debug_day_index` 之差，不当作日期。基准单独标记，切换时零点随之移动；无基准时以最早可比观测为第 0 天，同一观测只显示一个点 |
| 3 | 逐点结果、加工点位预测、观测图像、报警与维护 | 逐点表按测点和接近方向显示，表格上方不再重复显示指标名称；底部保留缺失条件提示，“历史记录”与“展开明细”并排。图像可切换本次/基准，历史使用对应快照；判定保留在“报警与维护”中，预测和维护流程未接入 |
| 4 | 机器人手眼参数及标题右侧状态灯 | 参数加载和编辑；版本等详情移到灯的悬停提示。手眼已加载为绿灯，仅视觉参数为黄灯，尚未加载为灰灯；调试窗口提供隔离仿真核验和独立相机、手眼标定入口，基准与复测通过主页面操作 |
| 5 | 测量基准及标题右侧状态灯 | “建立基准”使用当前载入观测，完整计算输入精确相同时提示已有基准，不重复创建或追加评估，也不自动切换。“选择基准”只列已建立的基准，相同内容合并显示，保留历史文件。切换在后台计算并显示进度，不清空历史或更换测量参数；条件不匹配则提示不可比较 |
| 6 | 右侧日志下方的采集、导入入口 | “采集靶标”“导入观测”与“清空日志”“评估精度”同排；不放“本次观测”标题和状态块，不另占整页栏位 |
| 7 | 判定与点位设置及标题右侧状态灯 | 三项指标共 12 个阈值均已设且有加工点位为绿灯，部分已设为黄灯，均未设为灰灯。设置数量与点位数放在悬停提示；阈值留空不判定，零值为有效设置 |
| 8 | 运行日志与处理进度 | 日志按日保存，重启恢复，可选择复制、滚动和清空当前显示；逐图处理使用进度条及单行状态，不逐张追加日志。多方向指标口径作为提示，不记为运行警告；缺少计算条件或数据等真实问题仍保留警告。清空按钮放在日志下方，与评估同排 |

“评估精度”通过服务计算并保存结果；当前重复定位在没有基准时也可单期评估，两项退化需要基准与本次观测比较。切换指标仅改变显示，不重新解算图像、不更换参数或基准。四个操作按钮与历史、明细等查看入口统一使用蓝底白字；设置按钮保留白底。

## 当前交互边界

- 所有下拉框统一使用原生列表展开方式：指标、趋势、观测来源、观测样本、基准选择和调试窗口标定方法都从选择框下方展开，不因当前选项改变弹出位置。统一由公共下拉框样式控制。
- 加工点位和阈值通过服务持久化。点位编号不能为空或重复，非空理论坐标须有效；“取消”不改动已应用配置。
- 点位理论坐标默认采用机器人基坐标系，是输入而非预测结果。新增点位后，X、Y、Z、空间指标的预测值均为“—”，判定为“待预测”。
- 趋势复用已保存位姿，按所选基准重新计算所有可比观测；核对参数、采样协议、程序、靶标及点位/方向。切换基准或早期历史开关不重新 PnP、不新增评估、不修改原历史快照。切换指标同步更新卡片、趋势、逐点表、预测标题和判定。
- 评价更新时间来自最新观测对应的已保存评估，与采集/导入时间分开保存。切换基准或阈值只改变当前比较视图，不伪造新的测量日期。建立基准时保存一次基准评估；启动恢复最新结果、当前载入观测、图片和日志。历史详情独立查看，主卡不随历史选中行改变。
- 启动恢复、基准核对与切换、历史计算和导入通过工作线程调用服务；回到主线程只更新界面，完成后才显示 100%。进度覆盖读取、比较、解算及保存各阶段；任务执行期间禁用相关操作，失败后恢复。已计算历史复用于指标和显示范围切换，更换基准或新增评估后更新缓存。采集靶标仍提示相机接口未接入，不伪造采集成功。
- 卡片按汇总值判红，报警详情按各指标对应分组判定，分别反映整体和局部状态；专利 V6 多方向三项指标均按点判定。RMS 退化量保留正负，负值不取绝对值报警；质心漂移显示幅度。主页面使用当前阈值并在修改后立即刷新；原历史详情和报警记录使用当时保存的阈值，不被后来设置覆盖。
- 阈值窗口只保留上限输入和保存规则，不附加指标解释。指标菜单、卡片标题及结果明细按结果自身的定义显示说明；无观测时不默认显示旧版 3σ / RP，当前多方向观测显示质心 RMS / 质心漂移，旧历史仍说明其原定义。
- 每点不同接近方向各一次的图片采用专利 V6 质心 RMS，至少两个方向才计算；这不等于同方向 RP。旧同方向协议仍要求同点同方向至少两次到达。专利质心漂移无需指令位置或初始绝对误差，但缺少基座参考朝向时三轴留空，空间模仍可计算。真实绝对误差及旧定义的误差变化仍需对应初始绝对误差，或固定靶标基座位姿与指令目标。
- 主轴页、轴向进给页和资源保持原状。页面沿用深色微软雅黑、白色面板及已有缩放。

## 实现位置

`app/pages/robot_position_page.py` 放置页面、设置弹窗和原生 Qt 趋势控件，经 `core/services/position_monitoring_service.py` 调用纯算法。仿真核验窗口在 `app/dialogs/robot_position_simulation_dialog.py`，相机与手眼标定窗口在 `app/dialogs/robot_camera_calibration_dialog.py`。指标选择复用 `resources/styles/light.qss` 中现有下拉菜单样式和缩放。
