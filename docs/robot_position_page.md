# 机器人定位精度监控页

机器人定位模块已接入本地参数、观测导入、基准管理、核心评估与历史。操作和输入格式见 [使用说明](robot_position_monitoring.md)。在线相机和控制器接口仍未接入，机器人运动由原设备软件负责。

## 监控依据

1. 采用已标定的相机到被评估末端（TCP）的手眼变换，不要求完整机器人运动学模型。手眼参数与初始测量基准分别管理，保留参数版本。
2. 机器人投入使用前，按固定程序、固定位姿拍摄靶标，保存初始观测基准。
3. 后续每次评估重复相同程序、位姿和靶标，通过视觉观测误差反映末端定位误差。机器人运动由原设备控制软件执行。
4. “机器人定位精度”标题右侧放置指标下拉菜单，独立于区域 1，标题与选择框垂直居中对齐。选项列表从框下方展开，不随当前选中项上下移动。菜单仅保留绝对定位精度退化、重复定位精度退化、当前重复定位精度，默认第三项，控制整个结果区。四列固定为基座 X、Y、Z 和空间指标，单位 mm；各项数学含义见使用说明。
5. 加工点位预测区域沿用当前所选指标，模型尚未接入，数值留空。加工点位与拍照观测点分别管理，预测值不能说成实测值。

视觉相对计算的依据来自原工程 `../SoftwareTools/AGENTS.md`“已确认的视觉末端定位监控原理”：相机与末端刚性连接，靶标相对基座固定，视觉输入包含完整旋转和平移，即使页面只展示位置指标也不能忽略视觉旋转。

用 `H` 表示相机到末端的手眼变换，`V_0`、`V_i` 表示基准、当前的靶标到相机变换。相对末端变换为 `ΔT_E = H V_0 V_i⁻¹ H⁻¹`，其平移 `p_ΔE` 在初始末端坐标系中表达。用户指定默认展示机器人基坐标系下的 XYZ，因此还需每个测量点的初始末端朝向 `R_E0`，按 `Δp_B = R_E0 p_ΔE` 转换；该朝向应关联到基准数据，具体获取接口待接入时确定，界面不增加坐标系选项。缺失朝向时不能把末端系分量直接当作基坐标分量。

单测量点的距离为 `||Δp_B|| = ||p_ΔE||`。这代表相对基准的位置偏移，不直接等同于当前绝对定位误差，也不等同于前后误差模长之差。先按同点、同方向计算，再按方向及测点等权汇总；轴向幅度平均使用绝对值，逐组保留正负。完整定义见 `AGENTS.md`。加工点预测方法仍待确认。

## 固定区域编号

编号沿用用户 2026-09-24 标注截图，后续说“区域 N”按下表理解。编号仅用于沟通、文档和代码定位，界面不显示数字标号或编号说明。

常用窗口采用左侧结果、右侧设置，宽度约 65:35。字体、图标、间距与控件随窗口统一缩放；右栏设计最小宽度 332，同样参与缩放。页面可用宽度小于 1000 时改为结果在上、设置在下，避免裁掉设置栏，通过纵向滚动访问。采集、导入、清空日志、评估四个按钮在设置栏日志下方同排。

| 编号 | 内容 | 操作与职责 |
| --- | --- | --- |
| 1 | 本次评估/基准批次；X、Y、Z、空间指标四列及对应阈值；所选指标判定 | 由标题行右侧的指标下拉菜单统一控制；标题、数值、单位、阈值文字与曲线同色。无结果为“—”，说明缺少哪些输入 |
| 2 | 所选指标的历史趋势 | 标题随评价指标切换；图例和“XYZ 三轴／空间指标”下拉框在同一行靠右，与左侧轴说明垂直居中对齐。该下拉框只改变曲线显示方式；纵轴 mm，横轴评估时间/批次 |
| 3 | 逐点结果、加工点位预测、观测图像、报警与维护 | 逐点表按测点和接近方向显示；底部“历史记录”与“展开明细”并排。图像可切换本次/基准，历史使用对应快照；预测和维护流程未接入 |
| 4 | 机器人手眼参数：加载状态、相机到末端（TCP）的变换关系、参数版本 | 参数加载和编辑；独立调试入口提供 PnP、手眼标定、基准与复测流程，不加载整机模型 |
| 5 | 测量基准：批次、采集时间 | 保存初始观测、程序、测点、参数和初始朝向；选择旧基准会恢复关联参数，需重新导入复测 |
| 6 | 右侧日志下方的采集、导入入口 | “采集靶标”“导入观测”与“清空日志”“评估精度”同排；不放“本次观测”标题和状态块，不另占整页栏位 |
| 7 | 三项指标阈值配置状态、加工点位数量 | 阈值弹窗有三个标签，各自设置 X、Y、Z、空间指标四个上限；留空不判定。点位管理功能保持原样 |
| 8 | 运行日志 | 显示时间、INFO/WARN/ERROR 与消息，可选择复制、滚动和清空；清空按钮放在日志下方，与评估同排，不放在标题旁 |

“评估精度”通过服务计算并保存结果；当前重复定位在没有基准时也可单期评估，两项退化需要基准与本次观测比较。切换指标仅改变显示，不重新解算图像、不更换参数或基准。四个操作按钮与历史、明细等查看入口统一使用蓝底白字；设置按钮保留白底。

## 当前交互边界

- 所有下拉框统一使用原生列表展开方式：指标、趋势、观测来源、观测样本、基准选择和调试窗口标定方法都从选择框下方展开，不因当前选项改变弹出位置。统一由公共下拉框样式控制。
- 加工点位和阈值通过服务持久化。点位编号不能为空或重复，非空理论坐标须有效；“取消”不改动已应用配置。
- 点位理论坐标默认采用机器人基坐标系，是输入而非预测结果。新增点位后，X、Y、Z、空间指标的预测值均为“—”，判定为“待预测”。
- 趋势控件只绘制当前指标中基准和参数版本一致的历史，并核对程序、靶标及测点/方向组合；独立单期评估的基准为空。切换评价指标同步更新卡片、趋势、逐点表、预测标题和判定；原图与右侧配置不变。
- 导入和计算通过工作线程调用服务，界面仅显示进度和结果。采集靶标仍提示相机接口未接入，不伪造采集成功。
- 三项指标分别按每点、每方向的对应值判定，整体均值不掩盖单点超限。退化量保留正负，直接与上限比较，负值改善不按绝对值报警。旧漂移阈值不迁用到新指标；历史使用该次计算保存的独立阈值，修改配置只影响下次评估。
- 两个接近方向各一次的观测仍不足以计算当前实现的同方向 RP，界面显示样本不足；缺初始误差或 Q 时不生成绝对精度退化。此次界面调整不重新定义这些数学量。
- 主轴页、轴向进给页和资源保持原状。页面沿用深色微软雅黑、白色面板及已有缩放。
