# 实时振动显示与实测数据回放

入口为“主轴回转精度监控”标题右侧的“实时监测”。沿用独立窗口、通道勾选、自动排版和现有颜色；三个波形框接入实测加速度，频谱、温度和转速保留占位布局。

## 使用

1. 点击“模拟采集”，选择完整原始采集目录，而不是处理后的 ZIP。
2. 后台读取 `manifest.json`、`segment_records.csv` 及全部振动 `.npz.xz`，检查通道、原始时间轴、采样率、缺片和非有限值，并确定固定纵轴。
3. 准备完成后按原采样频率和 1× 墙钟时间播放。可暂停/继续，停止后可重新选择目录；关闭窗口会暂停，退出主软件会释放后台回放。
4. “显示窗口”可选最近 0.5、1、5 或 10 秒，默认 5 秒。短窗口便于观察波形细节，两组公共时间轴同步切换，0.5 秒窗口每格 0.1 秒，1 秒窗口每格 0.2 秒。切换立即使用已经连续维护的对应缓冲，不跳回开头。取消通道勾选会移除图框，重新勾选显示当前最近窗口。
5. 三路振动波形使用相同大小的框，框内不显示横轴刻度；公共时间轴独立放在全部振动框下方，右端横排 `t/s`，不再另占一行标注“相对时间”。三路绘图区等高、左右对齐并保留网格。取消通道后自动收拢布局；没有勾选波形时公共轴也不占位置。
6. 八个图框均使用左侧竖排短标题。振动按“前轴 X（ACC2）、前轴 Y（ACC1）、台面（ACC3）”显示，保留原始通道对应关系；“波形”“频谱”仅在图组顶部各出现一次。窄窗口将波形组与频谱组上下排列。
7. 温度、转速框共用其下方的一条时间轴，均不在框内重复显示 X 轴。温度框内用小字彩色图例区分轴承温度 NTC1、环境温度 RTD1，图例随通道勾选更新；两类通道都关闭时，下面的公共轴一同移除。频谱、温度和转速当前仍未接入数据。

原始单位为 g。显示波形先做有状态抗混叠低通，再降低显示采样率；这只影响显示，不改写原始数据。每个波形标题的悬停提示标出原始采样率、显示采样率和显示带宽。长时间窗口无法同时完整呈现全部高频振动，设备健康评价仍沿用原始/正式分析流程。

## 绘图实现

- 参考 `docs/code/src/nidata_collector/ui/plot_resampling.py` 的分级椭圆低通，以及 `qt_app.py` 的环形缓冲与双曲线方式，移植到生产模块，不依赖参考文件夹运行。
- 后台解压一份原始分片，按约 20 ms 的原始样本块持续过滤，队列预读约 1 秒。界面用单调时钟决定哪些样本已经到达，不用绘图帧数代替采集时间。
- 0.5、1、5、10 秒各维护固定容量环形数组，新增样本只写入相应位置。每次刷新只把最近窗口的最多两段数组视图交给已有曲线，每路不超过 4096 点，不拼接 20 分钟历史。
- Qt 精确定时器约 33 ms 刷新；每路固定纵轴在准备完成时设置，播放时不自动缩放。用完整实测记录中各显示窗口的峰峰值中位数确定跨度，使常规波形中位占高约 70%，避免个别大峰值把普通波形压成细线。峰值超出显示范围时，波形框内右上角显示小字提示，曲线缓存与原始记录中的真实值保留。固定坐标不能保证幅值变化较大的每个窗口都恰好占满 60%～80%。
- 读取、解压和抗混叠过滤在后台运行；曲线与界面控件只在 Qt 主线程更新。样本计数、时间进度和渲染频率分别记录。
