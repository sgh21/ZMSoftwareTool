# 主轴回转精度监控页面

本页先供用户审阅布局。沿用机器人页的左侧结果、右侧设置，左右约 65:35；字体、图表及控件跟随窗口统一缩放，小窗口可纵向滚动。实现集中在 `app/pages/spindle_rotation_page.py`，使用原生 Qt 绘图，没有新增依赖。

## 业务流程

每次使用前，主轴由原设备软件按指定转速运行，监控模块采集振动、温度和电流。对同批数据分别进行数字信号分析与重建网络辅助评估，综合展示结论及解析依据。正常参考应匹配转速等工况，不能将工况变化直接解释为精度退化。

初期或日常采集的数据，由操作人员校核后决定是否设为正常信号、加入训练集，再单独启动训练。检测完成不自动加入训练集，也不自动更新模型。网络分数表征信号偏离正常分布的程度，不直接表示几何回转误差，不能标注成 μm 实测精度。

## 页面布局

| 位置 | 展示内容 | 用途 |
| --- | --- | --- |
| 左侧顶部 | 解析评价、网络评分、温度、电流；下方综合结论 | 先看到本次结果和设备状态，尚未评估时留空 |
| 中部左上 | 采集信号图，按信号类型 → 通道两级菜单选择 | 查看当前通道随时间的变化 |
| 中部右上 | 当前振动轴的频谱，正常与本次叠加 | 查看谱峰及不同频率成分的差异 |
| 中部左下 | 当前振动轴的频带能量分组柱状图 | 比较正常与本次在各频带的能量变化 |
| 中部右下 | 网络辅助评估分布图 | 当前方案叠加正常与本次的重建误差分布，直观看偏离程度 |
| 左侧底部 | 检测历史、预警记录 | 查看检测追溯与预警证据 |
| 右侧上部 | 采集方案、正常样本与网络、判定阈值 | 集中设置和训练管理 |
| 右侧下部 | 运行日志及同排四个蓝色按钮 | 日常采集、导入、清空日志和评估 |

参考样本统一用青色，本次信号统一用蓝色，整页共用一组“正常／本次”图例。主页面业务操作按钮用蓝底白字，设置入口用白底。训练入口与常用采集操作分开，避免把训练当作每次检测的必经步骤。不在本页显示区域数字编号。

信号入口收起时只显示“振动 · X”等当前通道；展开后一级为振动、温度、电流，二级为各自通道，并勾选当前项。切换振动轴时，同步切换时域、频谱与频带能量示意图；选择温度或电流时，只更新采集信号图，频谱和能量图保留上次选择的振动轴，标题标明轴名。网络图仍为整批数据的布局占位，不随单通道选择改变。

通道名单集中在 `config/display.json` 的 `spindle_preview_channels`，目前振动为 X/Y/Z，温度以 T1/T2/T3、电流以 I1 占位；温度数量及实际测点名称尚未指定，可直接修改该配置后重启预览。不同通道的示意曲线仅调整绘图幅值以展示切换效果，不代表实际传感器关系。

主页面只保留标题、通道、单位、图例和状态；重复说明移到悬停提示或本说明文档。人工确认正常的条件在复选框提示中说明，不再另占一行。日志初始为空，不主动填充说明性记录。

## 按钮与当前交互

| 入口 | 计划用途 | 当前预览行为 |
| --- | --- | --- |
| 采集设置 | 设置指定转速、采集时长、振动采样率 | 展示三个空字段，关闭不保存，不控制主轴运动 |
| 人工确认正常 | 操作者确认本批可作为正常候选 | 仅控制“加入训练集”按钮可用状态，悬停查看校核条件 |
| 加入训练集 | 把确认正常的本批信号加入正常数据集 | 日志提示尚未接入，不增加样本 |
| 训练网络 | 用正常样本学习正常分布，生成可追溯模型版本 | 日志提示未启动训练，不生成模型 |
| 样本与模型 | 查看样本批次、工况、人工校核及模型状态 | 空表，样本 0 批、模型未训练 |
| 阈值设置 | 仅配置网络评分、综合评价两类阈值 | 两个空字段，无预设工程阈值；关闭不保存 |
| 采集数据／导入数据 | 获取本次检测的三类信号 | 日志说明未开始采集、未读取文件 |
| 清空日志 | 清除当前界面日志 | 已可操作，不涉及历史数据 |
| 开始评估 | 对本批数据执行信号分析与网络推理 | 日志说明未接入，结果保持待评估 |
| 检测历史／预警记录 | 查看各批工况、结果、模型版本及预警依据 | 展示空表，不插入示意记录 |

解析评价展示频谱、频带能量等分析结果与依据，不单独设置振动指标或频带能量阈值。判定阈值仅有网络输出评分与综合评价两类；评分范围、综合评价方式及具体阈值待确定，本轮只调整界面。

## 示意图与后续接口

用户允许绘制占位曲线。顶部统一标识“示意数据”，悬停说明非实测，各图不重复标注。曲线只用于排版：时域、频谱、能量和分布各自独立，未对时域数据计算 FFT，也未计算能量或执行网络推理。温度、电流曲线的刻度同样是示例，不会写入顶部真实结果。

频带暂以 B1—B4 表示，不赋予故障诊断含义。网络图采用重建误差分布的叠加作为待审方案；不是已经训练出的正常信号模型，也没有把当前曲线视为已确认异常。最终的信号单位、窗口划分、频带边界、工况匹配、训练数据格式、评分范围、阈值及预警规则需在接入算法前确定。

本轮不实现设备通信、文件导入、信号处理、训练、推理或持久化。布局确认后，再明确这些输入输出并通过核心服务接入页面。
