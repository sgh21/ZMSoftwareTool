# 相机与手眼标定调试

入口：机器人定位页的“调试” → “相机与手眼标定”。标定后端位于 `core/services/camera_calibration.py`，桌面与 `debug/diagnostics/camera_calibration.py` 命令行入口共用；调用已有 ChArUco、PnP 和手眼函数，不改写这些核心函数。

## 使用步骤

1. 选择包含 `parameters.json` 和批次目录的数据根目录，标定批次选择 B000。
2. 相机内参选择“重新标定”。默认估计五项畸变；已知理想针孔的仿真数据也可明确选择固定零畸变。
3. 手眼选择“重新标定”或“读取记录参数”。重新标定时，按图像匹配机器人记录的 `B_T_E`，使用 PARK 或 TSAI；读取记录参数时使用 `E_T_C_hand_eye`。
4. 开始标定，查看重投影误差、固定靶标一致性残差和输出位置。后台运行期间不能更改输入或关闭窗口。
5. 返回主页面，通过“加载参数”加载输出的完整参数文件。标定窗口不会自动替换当前参数、观测或基准。

输出保存在 `data/processed/robot_camera_calibration/<时间>/`，包含完整系统参数、单独手眼参数和标定报告。原始图像、记录和主应用状态保持不变。

## 坐标与数据来源

- PnP 输出为 `C_T_M`：将靶标坐标转换到相机坐标。ChArUco 原点在图案左上角。
- 手眼为 `E_T_C`：将相机坐标转换到末端坐标。本仿真 E 是 tool0；平移统一使用 mm。
- 内参标定只使用图像角点和板几何；逐图真值外参不参与 PnP。
- 手眼标定需要与图像配对的机器人位姿。本数据使用 B000 的 `actual` 作为仿真机器人记录，报告保留该来源。监控测试中的 B001/B002 `actual` 只用于完成测量后的核验。
- 固定靶标基座外参沿用记录的 `B_T_M_charuco_top_left`，并注明来源。手眼标定拟合出的靶标位姿单独报告，不静默替换已知外参。
- 标定的重投影误差及固定靶标一致性残差用于评价本次标定数据，不能直接当作机器人定位精度。

## 本数据的后续流程

B000 用于参数准备；B001 的 600 张图建立初始基线；B002 的 600 张图进行退化复测。每点 20 个接近方向、每方向一次，评价的是多方向到位散布。B000 的 30 张图不复制为监控重复样本。
