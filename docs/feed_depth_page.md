# 进给轴窝深页面

页面已接入 90 天模拟数据生成、统计展示、理论设置、误差报警和 CSV 导出，CSV / Excel 文件读取与分组评估已接入。主窗口保留“主轴轴向进给精度”选项卡，页内标题为“进给轴窝深”，实现在 `app/pages/feed_depth_page.py` 的 `FeedDepthPage`。

## 页面与当前可用操作

- 左侧顶部保留四张统计卡，下方为两个上下排列的长方形历史图：平均偏差趋势、窝深标准差趋势，各占满左侧宽度。底部显示当前日期和孔数，并提供“历史记录”“孔位明细”。右侧放设置、运行日志、进度和操作按钮，“检测设置”标题右侧为“调试”入口。常用窗口按 13:7 排列；可用宽度小于 1000 设计像素时改为上下排列并纵向滚动，断点同步使用当前 UI 比例，放大字体后也不会裁掉右栏。
- 原“采集批次”下拉框用于选择哪一天的数据，现改为“历史记录”弹窗：双击记录或点击“查看批次”即可选择日期，也可直接点击曲线。主页面只显示简短的当前批次状态。
- 可以选择 CSV／XLSX 路径，选择路径不读取文件。已选文件路径放在“选择文件”按钮的悬停提示中；“理论窝深与报警设置”打开理论来源及误差范围设置，调试期间也可使用；“统计说明”按钮打开只读说明，不在主页面常显解释段落。
- 右下角统一使用“评估精度”名称，与机器人页保持一致；未载入数据时置灰并悬停提示先导入。“导入数据”在空闲时始终可用，未选文件时打开选择窗口；已选路径直接读取，导入成功后自动完成首次评估。后台处理期间按钮置灰并提示等待，完成或失败后恢复。未导入或进入模拟演示时实测统计显示“—”，表格和曲线为空；统一理论卡显示已保存的设置值。进入演示后保留简短的模拟数据来源标记。日志和进度反映实际生成、保存及刷新过程，状态行保持简短。
- 窝深统计暂不定义为进给轴精度评分。报警仅检查用户设置的误差范围，不据此归因设备故障。

## 使用 90 天模拟演示

1. 点击右上角“调试”，在弹窗中查看模拟配置和输出路径，点击“生成90天模拟数据”。弹窗关闭后，后台生成数据并导出文件，完成后默认查看最后一天。生成由 `core/services/feed_depth_simulation.py` 的 `generate_feed_depth_simulation` 执行；主页面不放模拟配置和路径框。
2. 打开左下角“历史记录”，双击日期或选中后点击“查看批次”；也可直接点击曲线切换日期。四张卡片、底部状态和“孔位明细”同步显示当日 30 孔；两个历史图始终保留完整 90 天。悬停查看日期、指标值和有效孔数。
3. 模拟原始理论窝深为 1.500 mm。演示期间可通过“理论窝深与报警设置”改用统一理论值，立即刷新卡片、完整 90 天的平均偏差、历史记录和孔位明细，并按当前误差范围判色；实测均值、方差和标准差不变。再次打开“调试”，点击“退出调试模式”恢复本次会话已导入的数据；没有已导入数据时恢复空态，已保存设置和导出的 CSV 保留。选择文件只记录待导入路径，导入成功后才替换当前显示；取消或失败保留原数据。

模拟区间为 **2026-07-11 至 2026-10-08**，每日一批、每批 30 孔，共 90 批、2700 孔；固定随机种子为 `20261008`。前 15 天整体稳定，第 16–60 天逐渐偏浅且散布增大，第 61 天起变化加速。模拟包含带相关性的日间偏移、固定孔位差异和逐孔噪声；每孔窝深先舍入到 0.001 mm，再据此计算卡片、曲线和汇总值。

所有结果均标记来源 `simulation`，属于演示数据。末日模型参数的偏差 −0.075 mm、标准差 0.024 mm 是生成设定，不是设备标定值，也不保证当日有限样本统计恰好等于这些数值。

每次生成写入独立目录 `data/feed_depth_simulation/<生成时间>/`：

| 输出 | 内容 |
| --- | --- |
| `hole_depths.csv` | 2700 孔的跨批汇总表 |
| `batch_summary.csv` | 90 批的均值、总体方差、平均偏差、总体标准差等统计 |
| `batches/` | 90 个逐批 CSV，每个文件 30 孔 |
| `metadata.json` | 模拟来源、参数和生成信息 |

跨批汇总表用于查看和分析；“一文件一批”的导入约定对应 `batches/` 中的逐批文件。导出内容保留在本地，不写入真实业务存储。

## 理论窝深与误差报警

设置由 `core/services/feed_depth_service.py` 校验并保存在 `storage/feed_depth/settings.json`，重启后恢复。逐孔模式使用原始数据中的理论值；统一模式使用填写的大于 0 的有限数值，单位 mm。应用设置只重算显示结果，不改原始模拟行、历史统计或已导出的 CSV。

输入无效时保留设置窗口，可以直接修改后再应用；取消不保存。设置在后台保存，保存失败保留原设置和显示结果；保存过程中关闭页面，已开始的文件写入可以完成，完成后不再更新已关闭的界面。

误差定义为 **实测 − 理论**。默认上下限都为空，不报警；用户按工艺填写有符号误差下限和上限，可以不对称。低于下限或高于上限才报警，等于边界正常。两项须同时填写有限数值且下限不大于上限；同时清空即可关闭报警。

- “平均窝深”卡片按当前批次的平均偏差判断，超限时实测数字变红。
- “孔位明细”按各孔偏差判断，超限孔的实测数字变红。平均正常也可能存在单孔超限，日志和状态提示保留超限信息。
- 改变理论值、误差范围或所选日期后立即更新判定；回到范围内恢复正常字体颜色。

模拟报警用于检查用户设定范围及显示效果，不代表真实设备精度评分、验收结论或故障归因。

## 导入文件格式

按下列约定读取与校验；Excel 读取使用 `openpyxl`，已列入 `requirements.txt`。每个文件代表一个批次，一行对应一个孔。CSV 使用 UTF-8（兼容 BOM），首行为字段名；XLSX 读取第一个工作表，首行为字段名。

| 字段 | 要求 | 含义 |
| --- | --- | --- |
| `hole_id` | 必填 | 孔号，按字符串保留前导零 |
| `actual_depth_mm` | 必填 | 实际窝深，单位 mm |
| `theoretical_depth_mm` | 逐孔模式必填 | 每孔理论窝深，单位 mm；统一模式不使用此列 |
| `row_id` | 可选 | 孔排号，缺失时整批视为一组 |
| `batch_id` | 可选 | 批次号，缺失时采用文件名；同一文件只对应一个批次 |
| `measured_at` | 当批统计可选，历史比较时提供 | 实际测量时间，缺失时留空，不以导入时间补写 |
| `condition_id` | 历史比较时提供 | 工况组，标识可比的加工和测量条件；同一批次内一致 |

同一批次内 `row_id + hole_id` 唯一。默认从每行读取理论窝深；也可以切换为统一填写一个正数。以选定模式确定理论值来源，不静默混用两种来源。

缺测不补零，须明确标出并排除出有效统计；非数值和重复孔记录报告行号并停止此次导入，原数据保留。模拟导出 CSV 的来源标记会继续保留。

## 统计与展示口径

按孔排和理论窝深分组，展示当前组的有效孔数、理论窝深、实测窝深平均值和总体方差。不同理论窝深不混为一组。

- 平均值单位 mm；总体方差分母为有效孔数 N，单位 mm²。N=0 时均值与方差均为空；N=1 时方差为 0，但不代表已验证重复性。
- 孔位明细保留孔排、孔号、理论窝深、实测窝深及有符号偏差（实测减理论）。

## 历史趋势的选择

在没有真实历史数据的阶段，先按指标含义选择两条互补曲线；尚未验证它们对本设备的退化检出效果。

| 曲线 | 每批统计值 | 用途 |
| --- | --- | --- |
| 平均偏差趋势 | b = mean(实测 − 理论)，单位 mm | 看整批偏深或偏浅；正值偏深、负值偏浅，远离零表示整体偏移增大，回到零可能是改善 |
| 窝深标准差趋势 | σ = √总体方差，单位 mm | 看孔间散布是否增大；与深度同单位，比方差 mm² 更直观 |

保留原平均值、方差卡片。绝对偏差会丢失偏深／偏浅方向；RMSE 将偏移和散布合在一起（同一理论深度、同一 N 口径下，RMSE² = b² + σ²），因此暂不占用两张诊断趋势图。

这项选择参考 [NIST 均值与标准差配套监控](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc321.htm) 和 [短期散布的历史监控](https://www.itl.nist.gov/div898/handbook/mpc/section2/mpc233.htm)。当前是描述性趋势，不是带控制限的控制图，不直接套用其样本标准差估计或报警规则。

导入历史与模拟历史均按以下规则显示：

- 每个点是一批内同孔排、同理论窝深的统计；跨批还需确认工况组一致，包括刀具、材料、加工参数和测量方法。缺少可比条件时可看当批结果，不能默认连成同一条历史曲线。
- 平均偏差至少一个有效孔；标准差趋势至少两个有效孔。单孔批次即使总体方差为 0，也标记“样本不足”并断线；有效孔数随历史记录保留。
- 横轴使用真实测量日期，批次时间取该组最后一次实测时间，并保留测量起止范围；缺少测量时间的批次仍可查看明细，不用导入时间补点。至少两个可比批次才形成趋势，不把不同批次的孔混成一个趋势点。
- 窝深变化可能同时受加工和测量条件影响，不能仅凭两条曲线归因于进给轴。未确认基准和判定标准前，不生成退化率或设备合格结论；误差报警仅按用户填写的上下限执行。

连续导入的批次保留在本次页面会话中；相同批次编号重新导入时替换当前会话中的该批数据，不修改原始文件。历史弹窗可选择批次分组，曲线只显示与所选组工况、孔排、理论值、来源类型相同且具有测量时间的数据。导入记录暂不跨启动恢复，理论和报警设置仍持久化。

## 导入处理顺序

确认路径及理论模式 → 后台读取与校验 → 错误时报告行号并保留原数据 → 按孔排和理论窝深分组 → 计算统计 → 刷新结果。

沿用页面调用服务、后台处理、Qt 信号更新界面的方式；处理、保存及刷新完成后进度才到 100%。
