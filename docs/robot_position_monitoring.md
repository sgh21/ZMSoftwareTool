# 机器人末端定位监控

模块读取固定靶标图像，解算六维位姿，建立初始基准并比较后续观测。机器人运动和实际拍照由设备软件负责；“采集靶标”尚未连接设备，加工点位预测尚未实现。

## 正常使用

1. **加载参数**：导入 JSON/YAML 参数文件，或在“参数设置”中填写相机、手眼和标定板参数。仿真的原生 `parameters.json` 可直接加载。
2. **导入观测**：在按钮菜单中选择同批次图片、批次目录、`record.json` 或已保存的观测结果。原图导入后后台自动测量，完成即保存观测文件，不必先评估。
3. **建立基准**：检查当前载入的观测后点击“建立基准”。使用的是这份观测，不是按时间寻找最新评估。基准保存当时参数并引用观测，同时计算并保存一次基准评估。“选择基准”只列出明确建立过的基准；仅导入或评估过的批次不会自动进入列表。
4. **评估精度**：基准可比时计算三项指标。没有可比基准也可评估当前散布，退化量留空。两期参数版本、采样协议、程序、靶标、点位与方向必须匹配，同点指令位姿须保持一致。
5. **查看结果**：标题右侧菜单统一控制卡片、趋势、逐点结果、判定与报警。顶部显示最新已评估观测相对所选基准的结果；XYZ 为基座方向，第四列为空间指标。查看历史记录或切换观测图像不改变顶部结果。历史详情保留原评估使用的基准和阈值。

建立基准前会逐项核对已有基准的完整计算输入：测量参数和版本、程序与靶标、采样协议、点位与方向、全部视觉位姿、指令位姿及参考数据。数值须精确相同，名称、文件路径和操作时间不参与比较；相同数据重新导入也能识别。这样能确认各项指标一致，不会仅凭显示到四位小数的汇总值合并不同观测。重复时提示对应的已有基准，不创建文件、不追加评估、不自动切换，用户可选择已有基准。此前已产生的重复项在选择列表中合并显示，原文件继续供历史追溯；当前选中的重复项作为该组代表保留。

页面固定使用“绝对定位精度退化”“重复定位精度退化”“当前重复定位精度”三个名称。多方向新评估按技术交底书 V6 分别显示质心漂移、质心 RMS 变化和当前质心 RMS；提示及明细明确这些定义。质心漂移不是实际绝对定位误差的增量，多方向 RMS 不是国标同方向 RP。该口径说明为指标提示，不作为运行警告；缺少计算条件或数据等真实问题仍保留警告。趋势核对采样协议、参数、程序、靶标、点位和方向，并统一相对当前所选基准计算。

“显示基准前历史”默认不勾选，选择会保存。当前所选基准对应第 0 天；勾选后，早期观测相对当前基准重新计算，并显示在横轴负天数位置。负退化量表示相对该基准有所改善。取消勾选仅隐藏曲线中的早期点，历史文件不删除。切换基准和显示选项复用已保存六维位姿，不重新解算图像、不新增评估记录。

启动恢复、基准核对与切换、历史计算和观测导入均在后台执行，开始即显示任务状态和进度。导入进度覆盖解算、图片托管和结果保存，界面结果更新完成后才到 100%。尚不能确定总量的阶段显示忙碌进度条；处理期间暂时禁用相关操作，完成或失败后恢复。已算历史保存在内存中，切换指标和早期历史显示范围复用结果；更换基准或新增评估后更新计算，修改阈值只更新判定。

真实观测的趋势优先使用采集时间，缺采集时间时明确采用导入时间；旧记录保留评估时间作为回退。横轴为观测时间与当前所选基准观测时间之差，以天计并保留真实间隔；切换基准时零点随基准移动，隐藏早期点不改变其余点的间隔。仿真横轴使用观测与基准已保存的 `debug_day_index` 之差，不把批次编号当成日期。没有基准时，以最早可比观测为第 0 天。重复评估同一观测只显示一个曲线点；真实导入、评价时间分别保存，调试天数不冒充实际采集日期。

## 参数与保存规则

表单保留相机、手眼、标定板三页。相机内参、镜头畸变、平移、旋转和标定板几何使用独立分类标题，填写约定放在小字提示中。

| 配置 | 内容 |
| --- | --- |
| 相机 | `camera_matrix` 为 3×3 内参，fx/fy/cx/cy 单位 px；`dist_coeffs` 支持 0、4、5、8、12、14 项 |
| 手眼 | `hand_eye = E_T_C`，将相机坐标变换到被评估末端；平移单位 mm，必须对应实际评价点 |
| 普通棋盘 | `board_type: checkerboard`，`board_grid` 填内角点列数、行数 |
| ChArUco | `board_type: charuco`；`charuco.squares_xy` 填方格总列数、行数，另填 `dictionary` 和 `marker_length_mm`；已有 `marker_ids`、`legacy_pattern` 保留 |
| 方格尺寸 | 两类板共用 `square_size_mm`，始终为 mm |
| 固定靶标外参 | 可选 `target_pose_base = B_T_M`，表示靶标在基座中的固定位置和朝向 |
| 测量条件 | 可选 `image_size_px`、重投影误差上限 `max_reprojection_error_px`；普通棋盘还可配置 `reference_rotation` 保持角点顺序 |

表单 XYZ 单位为 mm，RPY 单位为 °，固定轴旋转约定为 `R = Rz(Yaw) Ry(Pitch) Rx(Roll)`；计算依据仍为完整矩阵。可选位姿须六项一起填写或全部留空，未修改数值与矩阵保留原精度。`end_frame` 若为 `tool0`，评价对象就是 tool0，不能当作已加工具偏置的钻尖 TCP。

缺少 `B_T_M` 仍可相对监控；有它才可由视觉直接恢复基座中的末端位置。绝对定位误差还需要相应指令位姿，不能只凭手眼或一个旋转矩阵得到。

参数文件接受 `length_unit: mm/m`，手眼与靶标外参平移在导入边界统一为 mm。完整配置会恢复其中缺失配置的默认值，避免从上一份 ChArUco 参数继承外参等条件；仅手眼文件仍按局部导入。旧 `T_tool_cam` 按其原约定从 m 转成 mm。

当前参数只保留一个默认文件和一个滚动备份：

- `storage/position_monitoring/parameters/current.json`：重启直接加载的当前参数。
- `storage/position_monitoring/parameters/previous.json`：实改前的上一版；后续实改覆盖此备份。
- 有效参数未变时，不重复保存、不生成版本，也不清除当前观测。真正改变参数后需重新导入观测。
- `config/robot_position.json` 仅作首次默认模板。旧 `state.json` 的参数首次迁入 current；已有 current 优先。state 保存设置、所选基准、最新观测及最新评估的引用，旧时间戳备份不自动删除。
- 历史基准的参数快照独立保留。“选择基准”不替换当前测量参数、不清除已载入观测。基准与最新观测的参数或测量条件不匹配时明确提示不可比较，不用较早的兼容批次冒充最新结果。

外部原始参数文件不会被覆盖。

当前载入观测与最新已评估观测分别管理。“建立基准”“评估精度”操作当前载入观测；顶部展示最新已评估观测相对当前基准的结果，按观测时间识别最新批次，重评早期批次不使它变成最新。重启恢复这些引用、图像与日志；旧版切换基准造成的空引用会从已保存历史恢复。历史原结果在独立详情窗口查看，不替换主页面结果、当前参数或观测。

## 图片与观测结果

固定命名为 `B000_P001_D001.png`：B 是批次，P 是固定目标位姿，D 是接近方向，均为三位数字。不同批次的同一 P、D 必须保持相同目标和方向定义。同批次、同点、同方向只导入一张图；不能用复制图片增加样本数。

可导入多张同批次图片、单批目录（如 `B001`）、目录内 `calibration_images/`，或批次 `record.json`。记录文件的 `frames` 关联 `image` 与 `ideal`，其中 `ideal` 为该图片的指令 `B_T_E`；可选 `actual` 为仿真核验真值。只有图片而没有指令位姿时，可计算满足条件的散布，但绝对误差留空。

原图通过棋盘或 ChArUco 检测和 PnP 解算 `V = C_T_M`。仿真 `actual` 及逐图真值外参不代替图像测量、不初始化 PnP，也不作为识别失败时的替代结果；已知相机内参、固定手眼及固定 `B_T_M` 是测量配置。

导入完成后自动保存 `storage/position_monitoring/observations/<时间戳>.json`，日志显示路径。文件包含批次、点位、方向、样本编号、图像路径、参数版本与快照，以及每张图的：

- `vision_pose`：完整 4×4 六自由度视觉位姿。
- `vision_xyz_mm`、`vision_rpy_deg`：便于查看的 XYZ 和 RPY；矩阵为计算依据。
- 检测质量信息，如重投影误差；有手眼及靶标外参时另存 `end_pose`、`position_base_mm`，有指令位姿时存 `error_base_mm`。

观测结果可再次加载，复用已解算矩阵而不重跑 PnP；参数版本必须与当前一致，否则需恢复对应参数或重新导入原图。任意两份观测只有满足同一采样协议和点位、方向、参数等可比条件，才可比较。

导入后的图片由软件复制到 `storage/position_monitoring/images/` 托管，并保留原来源路径。同一来源且文件未变化时复用已有副本；重复评估引用原观测文件，不再次复制整批图像和观测。原始图片和记录保持只读。后台逐图进度显示在日志下方的进度条和一行状态中，操作日志保存开始、完成和异常等信息。

真实观测按本地观测日期集中写入 `daily/YYYY-MM-DD.json`，同一天的导入、基准和多次评估追加到同一文件；操作日志为同目录的按日 JSONL。仿真调试按 `debug/day_0000.json` 等文件保存。历史仍可读取旧 `history/` 记录；新评估不再每次生成一份独立历史 JSON。

## 多方向指标的计算含义

当前图片协议是每点不同方向各到达一次，按专利技术交底书 V6 计算**相对多方向到位质心的 RMS 散布，不是国标同方向重复定位精度 RP**。一次停留连续拍照也不能当作不同到达。新结果保存 `metric_definition: patent_v6_rms`，用于区分历史定义。

设 `H = E_T_C`，`A = B_T_M`，视觉测量为 `V = C_T_M`。有固定靶标外参时：

$$
X = {}^B T_E = A V^{-1} H^{-1},\qquad p=\operatorname{trans}(X).
$$

缺少 A 时，以同点固定参考视觉位姿 `V_r` 计算 `D = H V_r V^{-1} H^{-1}`，再取其平移。该式保留手眼安装偏置与旋转影响，不能直接相减视觉平移。空间散布仍可计算；基座 XYZ 还需对应参考末端朝向 Q，不默认使用单位旋转。

同一时期 k、点 i 的 D 个方向位置记为 `p_ikd`。用实际基座位置或同一固定参考下的位置计算：

$$
\mu_{ik}=\frac1D\sum_d p_{ikd},\qquad
S_{ik}=\sqrt{\frac1D\sum_d\|p_{ikd}-\mu_{ik}\|^2},\qquad
U_{ik,a}=\sqrt{\frac1D\sum_d(p_{ikd,a}-\mu_{ik,a})^2}.
$$

空间散布为 S，三轴为分量 RMS，分母均为方向数 D，不使用 D−1，也不乘 3。逐点满足 `S² = U_X² + U_Y² + U_Z²`。散布退化分别为 `S_k − S_0`、`U_k,a − U_0,a`，正值增大、负值减小；方向数少于 2 时留空。

菜单“绝对定位精度退化”按专利显示同一点多方向质心相对基准的变化：

$$
\delta_{ik}=\mu_{ik}-\mu_{i0},\qquad
G_{AP,ik}=\|\delta_{ik}\|,\qquad G_{AP,ik,a}=|\delta_{ik,a}|.
$$

这是相对基准的质心漂移幅度，只表示变化大小，不能凭其正值断定实际绝对误差变差。它不是 `||e_k||−||e_0||`，也不是各方向位移模长的平均。无需指令目标或初始绝对误差；相对观测缺少参考基座朝向 Q 时，空间模仍可用，基座 XYZ 留空。所有三个指标先逐点计算，再各点等权平均；缺值不静默减少权重。

有 A 和指令位置 q 时，每方向实际绝对误差 `e_ikd = p_ikd − q_i` 及其误差模长差继续保留为诊断量，不替代专利质心漂移。旧多方向历史没有上述定义标记时，原记录仍按空间 `mean(l)+3std(l, ddof=1)`、三轴 `3std(p_a, ddof=1)` 和绝对误差模长差解读；历史窗口明确标注“旧定义”，不把旧数值当成 RMS。旧同方向 RP 定义保持不变。

三项指标分别设置 XYZ 与空间上限。顶部卡片分别用显示的汇总值与对应上限比较，超限才标红；新多方向指标均逐点报警，局部超限仍在报警详情中保留。因此卡片未标红不等于所有测点均合格。RMS 退化的负值不取绝对值判超限，缺值或缺阈值不标红。

多方向阈值存于 `multidirectional_thresholds`，旧同方向协议存于 `metric_thresholds`，两者不混用。主页面按当前设置判定，保存阈值后立即刷新；原历史评估保留当时阈值与判定，查看历史不会被当前设置改写。

升级后原多方向阈值数值保留，应按 RMS / 质心漂移的新定义复核。重启时主界面和趋势从保存的完整视觉位姿重新计算；历史原记录保留旧定义，不改写其数值。

### 惯性系数与理论值的对应

仿真停止位置为 `p_d = c + 2k d`，其中 `c = p_ideal + b`，d 是各接近方向单位向量。k=0.1 时，每个停止点距模型中心 c 均为 0.2 mm；0.2 mm 是半径，不是中心相对理想目标的偏移。后者由 b 决定。

设方向均值 `d̄ = mean(d)`，则样本质心 `μ = c + 2k d̄`，专利 RMS 的精确理论值为：

$$
S=2|k|\sqrt{1-\|\bar d\|^2}.
$$

方向成对对称或方向均值为零时，k=0.1 对应 RMS=0.2 mm。有限方向不完全对称时，RMS 略小于 0.2 mm；不能为了等于半径而改用已知模型中心替代测量质心。旧 `mean(l)+3std(l)` 和三轴 3σ 本就可能大于这个半径。不同批次的质心漂移还含 `(b_k−b_0)+2(k−k_0)d̄`，不能直接把 k 的变化当成中心偏移。

图像测量另含角点定位和 PnP 位姿误差。理论值、record 中的停止位姿真值、图像解算值须分别比较；不能用 actual 覆盖测量结果，也不减去一个固定“视觉噪声”。

## 坐标换算与旧协议定义

本节保留原 AGENTS.md 中的坐标约定和旧协议定义。当前多方向新评估使用上文的专利 V6 RMS 与质心漂移；旧协议与历史数值按各自定义解读。

`B/E/C/M` 分别为基座、被评估末端、相机和靶标，`A_T_B` 把 B 系坐标转换到 A 系。`H=E_T_C`、`V=C_T_M`、`A=B_T_M`。内部长度统一为 mm，旧 m 输入只在导入边界转换。手眼须对应实际评价点；若只标定到法兰，应合入法兰到 TCP 的变换，仿真 tool0 不能称为已加钻尖偏置的 TCP。

相对变换 `D=H V_r V⁻¹ H⁻¹` 必须保留完整旋转和平移。若 `H=[R_h,h]`、`V_r V⁻¹=[R_c,t_c]`，则 `R_D=R_h R_c R_hᵀ`、`trans(D)=R_h t_c+(I−R_D)h`，不能忽略安装偏置与旋转耦合。基座变化 `u=Q trans(D)` 需该参考的末端基座朝向 Q；缺 Q 时基座 XYZ 留空，空间模仍可计算。控制器或指令朝向应标明近似来源。

Q 只能提供坐标转换，不能确定绝对误差。旧相对协议需对应点、方向的初始绝对误差向量 `e_0`，才可由 `e_k=e_0+δ` 恢复，其中 `δ=μ_k−μ_0`，两期均值使用同一参考。有固定 A 和指令位姿时，直接由 `X=A V⁻¹ H⁻¹` 恢复末端，再计算 `e=p_actual−p_command`。旧定义的绝对退化为空间 `||e_k||−||e_0||`、分轴 `|e_k,a|−|e_0,a|`，正值表示变差、负值表示改善；漂移幅度 `||δ||` 不能充当这个误差模长差。

同点同方向的独立重复到达才属于同方向 RP 样本：`l_n=||u_n−μ||`、`RP=mean(l)+3 std(l,ddof=1)`；轴向补充量 `U_a=3 std(u_a,ddof=1)`，不是国标唯一分轴 RP 定义。N<2 留空；标准试验为 30 次循环，少样本不宣称完整国标试验。旧多方向历史采用同形式的空间散布与分轴量，不能冒称同方向 RP；连续拍多帧不增加到达次数。

`vAP=max ||μ_d1−μ_d2||` 是方向均值间最大距离，不能叫 RP。GB/T 12642—2013（ISO 9283:1998）7.2.3 对应三个正交接近方向，其他布置按实际条件说明；长期有符号退化是监控扩展，不等同于标准 7.6 冷态/热态试验的绝对差 dAP/dRP。实施参考为 GB/T 20868—2024。

旧绝对误差与同方向 RP 先按方向等权、再按测点等权汇总；多方向散布按点等权。空间汇总来自逐组空间指标，不由三轴独立最大值合成。缺组不静默改变权重，旋转坐标须变换全部样本或完整协方差。

ChArUco 原点在图案左上角 M，固定 A 必须对应 `B_T_M_charuco_top_left`；普通棋盘沿用居中物点。ChArUco 按 ID 对应物点，允许部分角点，至少 4 个且非共线。重投影误差 px、视觉平移误差 mm、tool0 位置误差 mm 是不同量；视觉姿态误差经逆变换和安装偏置也会影响末端位置。完整六维位姿用于正确换算位置，当前主指标仍为基座 XYZ 和空间位置量，不增加姿态精度评价或任意坐标系切换。

## 仿真核验与旧格式

点击“调试”，选择同时包含 `parameters.json`、`B001/record.json`、`B002/record.json` 的仿真数据根目录，选择基准与复测批次，默认 B001／B002，再点击“开始仿真核验”。程序重新测量两期图片，完成测量后才使用 actual 核验末端位置、姿态和三项指标。

窗口展示测量值、真值、测量减真值，以及末端误差均值、95% 分位数和最大值。报告为 `data/processed/robot_position_simulation/<时间戳>/verification.json`，同目录保存独立服务状态、观测和评估；主页面参数、基准与结果不会被这次核验替换。B000 每点只有一个方向，不能复制成多次样本；其方向不足以计算多方向散布，也不能直接与方向集合不同的批次比较。

旧 JSON/YAML 清单继续支持 `point_id/direction_id/sample_id` 和 `image_path` 或 `vision_pose`。未声明多方向协议的旧清单仍按同方向多次到达计算 RP；不足两次留空，不能因方向数多就改当重复次数。旧相对监控的基座分量依赖 `base_rotations`，绝对误差恢复依赖有依据的 `initial_errors`，具体定义见上文 [坐标换算与旧协议定义](#坐标换算与旧协议定义)。

相机与手眼标定统一从调试窗口的“相机与手眼标定”进入，处理配对图像及机器人位姿，手眼方法支持 PARK/TSAI，详见 [标定操作说明](camera_hand_eye_debug.md)。手眼一致性残差不等于机器人绝对定位误差。观测保存在 `storage/position_monitoring/observations/`，基准保存在 `baselines/` 并引用对应观测；新评估集中在 `daily/` 或 `debug/`，原始图像与记录只读。
