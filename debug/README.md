# 软件调试入口

在工程根目录的 `ZMSoftware` 环境中执行：

```powershell
python -m debug reset
```

清空使用数据并打开调试窗口。窗口已经通过 `python -m debug` 启动时，在另一个终端执行同一条命令，会刷新现有窗口，保留窗口大小和当前选项卡。只打开调试窗口、不清数据可执行 `python -m debug`。

reset 删除机器人观测、基准、托管图片、评估历史和日志，以及主轴导入副本、模型、标签和检测历史。保留机器人参数文件、两类业务阈值、加工点位配置及其他设置；主轴阈值与旧模型的关联清空，新训练后仍需复核阈值。原始 `data/`、仿真输出、`config/` 和复现报告不受影响。

任务正在执行或弹窗未关闭时，reset 会返回原因，不清数据；操作结束后重新执行。reset 直接删除历史，不生成备份。

所有命令和刷新逻辑均在本目录，正式入口 `python main.py` 不加载。调试入口与正式入口使用同一份本地存储，使用前先关闭通过 `main.py` 打开的窗口，避免多个进程读写相同数据。正式发行不包含本目录即可去掉 reset 能力。
